# ZError 全量题库 · 导入说明

本包是把 ZError 本地题库（18 个课程文件夹、**28908 道题**）整体导出，供另一台电脑一键导入。

导出于 2026-11-16。

---

## 一、包内文件

| 文件 | 用途 |
|---|---|
| `tiku_all.json` | 全量题目（约 10 MB），**导入用这个** |
| `tiku_all.csv` | 同一份内容（UTF-8 带 BOM），Excel 双击即可查阅，不必导入 |
| `import_tiku.py` | 导入脚本，只用 Python 标准库，无需 pip 安装任何东西 |
| `导入ZError.bat` | 双击即可调用上面的脚本（自动找 Python） |
| `导入说明.md` | 本文件 |

---

## 二、使用前提

1. Windows 电脑，已安装 ZError，并且**先正常打开过一次**。ZError 首次运行才会创建数据库
   `%LOCALAPPDATA%\ZError\airesponses.db`（通常在 `C:\Users\你的用户名\AppData\Local\ZError\airesponses.db`）。
2. 已安装 Python 3。安装时请勾选 **Add python.exe to PATH**。
   没装的话到 <https://www.python.org/downloads/> 下载即可；本脚本不依赖第三方库。

---

## 三、导入步骤

1. **先关闭 ZError**（程序开着时数据库被占用，写入会失败）。
2. 把整个压缩包解压到任意目录（**不要只把文件单独拖出来**，脚本和 json 必须在同一层）。
3. 双击 `导入ZError.bat`。
   或在解压目录里打开命令行执行：
   ```
   python import_tiku.py --apply
   ```
4. 看到类似输出即成功：
   ```
   写入完成: 前 0 条 → 后 28908 条，本次插入 28908 条
   ```
5. 打开 ZError，进入题库页面，左侧会出现 18 个课程文件夹。

### 想先看统计、不写库

```
python import_tiku.py
```
干跑只打印题量分布，不改数据库；确认没问题再加 `--apply`。

### 数据库不在默认位置

```
python import_tiku.py --apply --db "D:\某个路径\airesponses.db"
```

## 四、重复导入与去重

- 脚本按「**文件夹名 + 题干**」判重，已经存在的题会跳过，重复运行不会翻倍。
- 每次 `--apply` 写入前会自动把数据库备份成
  `airesponses.db.bak-年月日-时分秒`，放在数据库同目录。
- 因此你可以随时放心重跑，甚至先导一次、以后再补导新题。

### 后悔了怎么回滚

1. 关闭 ZError；
2. 在 `%LOCALAPPDATA%\ZError\` 下找到最近一次的 `airesponses.db.bak-2026...`；
3. 把它重命名覆盖回 `airesponses.db`（旧的先留一份）即可。

## 六、数据口径（想自己改数据时看）

ZError 的题库就是 SQLite 表 `AIResponses`，字段写法如下，`tiku_all.json` 里的内容与之对应：

| 字段 | 内容 |
|---|---|
| `Question` | 题干 |
| `Options` | `A. xxx  B. yyy`（两个空格分隔）；判断题/填空题为 `null` |
| `Answer` | 答案写**选项原文**而不是字母：单选＝正确选项文字；多选＝各选项文字用 `###` 连接；判断＝`正确`/`错误`；填空＝答案正文（多空用 `###`） |
| `QuestionType` | `single` / `multiple` / `judgement` / `completion` |
| `IsAi` | 写入时固定为 `0`（标记为非 AI 生成的题库题） |
| `FolderId` / `FolderName` | 按课程分文件夹，`ParentId=0` |

`tiku_all.json` 一条记录长这样：

```json
{
  "id": "Z00001",
  "folder": "毛概",
  "qtype": "single",
  "question": "……",
  "options": "A. ……  B. ……",
  "answer": "……"
}
```

## 七、常见问题

**提示找不到 ZError 数据库**
先启动一次 ZError 再关掉；或安装位置不同，用 `--db` 指定实际路径。

**提示 PermissionError / database is locked**
ZError 还开着（包括后台托盘），彻底退出后重跑。

**命令行里中文是乱码**
用 `导入ZError.bat` 运行（脚本里已做编码切换），或在命令行先执行 `chcp 65001`。

**导入后题没出现**
确认打开的是同一个用户账户下的 ZError；也可重新运行 `python import_tiku.py` 看统计，若提示"实际待写入 0"说明这些题本来就在库里。

**课程文件夹想合并/改名**
直接改 json 里的 `folder` 字段再导入即可；已导入的部分请先在 ZError 里删除，否则会按题干判重跳过。
